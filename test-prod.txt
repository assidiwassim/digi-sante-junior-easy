3. PARCOURS DE TEST CONSEILLE (10 minutes)
-------------------------------------------------------------------------------

ENFANT (lea / enfant123)
  1. Accueil : jauge du temps d'ecran du jour, avatar, prenom.
  2. « Mon journal » : les 4 enfants ont deja un journal aujourd'hui, donc la
     page affiche directement les conseils. Pour tester le formulaire en
     2 etapes, voir la section 4 ci-dessous.
  3. « Decouvrir » : la bibliotheque, groupee par type de contenu.
  4. « Mon profil » : carte d'identite et changement de mot de passe.
     (Si vous changez le mot de passe, notez-le : la connexion suivante
      utilisera le nouveau.)

PARENT (parent@digisante.local / parent123)
  1. Tableau de bord : journal du jour de l'enfant, jauge, douleurs signalees,
     conseils recus, graphique 7 jours.
  2. Basculer sur « 30 derniers jours » : la courbe change d'echelle.
  3. Changer d'enfant avec les boutons en haut (Lea / Tom).
  4. « Mes enfants » : ajouter un enfant (l'identifiant de connexion est
     genere automatiquement a partir du prenom), modifier, supprimer.
  5. « Mon profil » : email, ville, pays, mot de passe.

ADMINISTRATEUR (admin@digisante.local / admin123)
  1. « Contenus » : creer, modifier, supprimer une fiche / video / quiz.
     Un contenu rattache a une regle est propose a l'enfant dans ses conseils.
  2. « Parents » : liste des comptes, fiche d'un parent avec ses enfants en
     lecture seule, suppression d'un compte (definitive, en cascade).

CONTROLES D'ACCES (a tester, cela doit ECHOUER)
  - Un parent qui ouvre /admin              -> erreur 403
  - Un enfant qui ouvre /parent             -> erreur 403
  - Un visiteur non connecte qui ouvre /parent -> renvoye vers /login
  - /parent/enfants/<id d'un enfant d'un autre parent>/modifier -> 403


-------------------------------------------------------------------------------
4. REMETTRE LES DONNEES A ZERO (sur le serveur, en SSH)
-------------------------------------------------------------------------------

Les enfants de demonstration ont deja rempli le journal du jour. Pour tester le
formulaire en 2 etapes (temps d'ecran + schema du corps) :

  cd /home/user/digi-sante-junior-easy
  alias dcp='docker compose --env-file .env.prod -f compose.prod.yaml'
  dcp exec app php bin/console dbal:run-sql "DELETE FROM journal_entree WHERE date = CURDATE()"

Pour recharger entierement le jeu de demonstration (EFFACE toutes les donnees,
y compris les comptes crees pendant les tests) :

  dcp exec app composer install
  dcp exec app php bin/console --env=dev doctrine:fixtures:load --no-interaction
  dcp exec app composer install --no-dev --optimize-autoloader
  dcp exec app php bin/console cache:clear


-------------------------------------------------------------------------------
5. ACCES TECHNIQUES (reserves a l'administrateur du serveur)
-------------------------------------------------------------------------------

phpMyAdmin et MySQL ne sont PAS exposes sur Internet en production.
Pour y acceder depuis votre machine, ouvrir un tunnel SSH :

  ssh -L 3308:127.0.0.1:3308 root@vps1501
  puis se connecter a 127.0.0.1:3308 avec un client MySQL.

Les identifiants MySQL et APP_SECRET se trouvent dans le fichier .env.prod du
serveur (non versionne, chmod 600). Ils ne doivent figurer dans aucun document
partage.

Journaux de l'application :
  dcp logs --tail 50 app
  dcp exec app tail -50 var/log/prod.log
