# Captures d'écran de référence

Captures de l'application terminée (ce dépôt), prises avec les données de
démonstration de la phase 12. Elles montrent le **rendu attendu** : chaque
prompt de [`../prompts/`](../prompts/) indique, dans sa section « Captures
d'écran de référence », les fichiers à joindre.

## Comment les joindre au prompt

1. Ouvrez le prompt de la phase et repérez la liste des captures.
2. Dans Claude Code, glissez chaque fichier de ce dossier dans la fenêtre (ou
   ouvrez l'image, copiez-la, puis collez-la avec Ctrl+V).
3. Collez ensuite le texte du prompt et envoyez le tout.

> Joignez **uniquement** les captures listées par le prompt : une capture d'une
> phase suivante pousserait Claude Code à anticiper.

Format : bureau en 1280 px de large, pleine page ; les fichiers `-mobile`
sont pris en 390 px de large (écran de téléphone).
